# 三队形局部图记忆策略实验协议

登记日期：2026-11-05（Asia/Shanghai）。研究对象是五机器人在原渐缩通道中的编队导航。当前仅训练和评测 G 策略，line、circle、wedge 分别训练独立网络。训练前冻结本协议、机器可读配置、源码快照及场景清单；所有种子和失败结果均保留。

## 研究问题与证据范围

本轮回答三个问题：同一局部图注意力＋GRU 策略能否分别学习三种队形的通过与恢复；初始纵向不同步如何影响成功与恢复；在不重训的情况下，策略能否迁移到不同出口宽度。宽度测试只改变原渐缩通道的宽度参数，不增加新地图、额外规划器或新研究机制。

每种队形拥有自己的五个训练种子及所选网络。本轮没有训练一个能在三队形间切换的通用网络，也没有复现原论文 AFOR 控制器。已有模型、旧开发场景与旧结果移至活动项目外归档，不能作为本轮训练样本、测试样本或新结果拼接入表。

## 固定物理、训练分布与预算

| 项目 | 固定设置 |
|---|---|
| 算法 | G：局部图注意力、64维本机GRU、独立局部critic、PPO；详见 [METHOD.md](METHOD.md) |
| 队形 | line / circle / wedge，各自独立训练 |
| 训练seed | 11、23、37、51、67；三队形均使用完整五seed |
| 训练预算 | 每次500更新，共15次从零训练 |
| 采样 | 16个并行环境，每更新128步；每次1,024,000团队步、5,120,000机器人步 |
| 总采样量 | 15,360,000团队步、76,800,000机器人步；验证/测试不计入训练采样 |
| 物理 | dt=0.05s，半径0.13m，原渐缩通道，逐轴速度与加速度界限均为1 |
| 训练宽度 | 固定1.2m |
| 回合上限 | 750步，即37.5s |
| 初态扰动 | 每次reset以0.5概率扰动；幅值先从U[0,0.10m]取样，再为每机器人独立取U[−幅值,+幅值]纵向偏移 |
| 起终点 | 保留原随机平移、每机器人最终指定槽位；无中间槽位、宽度输入或全局阶段标签 |
| PPO | lr=3e−4，γ=0.99，GAE λ=0.95，clip=0.2，4 epochs，序列长度16，每批64序列，熵系数0.001 |

扰动后的整支团队必须初始无碰撞；拒绝非法提议并记录重试次数，不按后续成败筛选。训练场景、验证场景和测试场景使用互不相同的随机种子。相同队形的所有网络评估相同的预生成场景及其哈希。

500更新是预先固定的工程预算，不保证三队形都收敛。700 episodes不能换算成相同更新数；当前训练的回合终止长度又随策略变化，不能用原文700 episodes证明本预算充足。若 Circle 或 Wedge 较低，应报告学习曲线、选中更新、碰撞和超时原因；不能为获得正结果而隐去seed、更换成功定义或在本轮测试后延长某组预算。

## 验证选点与模型冻结

验证seed为 **172001、172002**。每25更新在宽1.2m、扰动0/0.05/0.10/0.15m下评估，每seed每条件24回合，共192回合；第25至500更新共20次。每次训练共3,840次验证回合，15次训练合计57,600次。

检查点按下列字典序排序：先比较零扰动团队成功数，再比较0.05/0.10/0.15m主挑战成功总数，成功数均相同则选择主挑战平均失败惩罚耗时更低者；完全并列保留更早更新。每次仅维护一个当前最佳模型。`actor.pt`是所选策略，`final_actor.pt`是第500更新终点；运行记录必须标明实际 `selected_update`。

验证保持训练随机流及模型模式，且不回滚权重继续训练。压力条件、宽度迁移、联合压力和测试seed均不参与选点。训练完成并登记所有权重哈希后，再一次性执行独立测试；不能根据测试分数重选checkpoint或seed。本轮独立测试仅评估15个所选模型；终点网络保留供重现诊断，终点开发验证得分可与所选模型对照，不重复计为独立测试或新增训练seed。

## 独立验收与统计定义

团队成功须同时满足：无任意时刻的机器人对、墙体或场地边界扫掠碰撞；五台均从实际出口通过；每台距自己的最终目标严格小于0.30m、速度严格小于0.15m/s；满足最终队形几何约束并连续维持10步。

最终队形约束沿用任务：所有名义边的最大长度误差<0.10m；Line另要求全队y跨度<0.15m，Circle/Wedge另要求去平移后最大模板偏差<0.10m。通道内允许形变，不额外要求全过程保持刚性模板。独立NumPy float64扫掠几何和最终验收核对训练环境，碰撞提议终止整回合，不能在回退后继续取得成功。

每回合保留团队成功、通过、碰撞类型、超时原因、终态误差、最小净距及以下过程量；只对首回合计数，已终止环境的后续reset不进入同次测试。

| 指标 | 定义及解释 |
|---|---|
| 失败惩罚耗时 | 成功时取回合完成时间；失败统一按37.5s。主效率指标对全部回合求均值 |
| 实际完成时间 | 仅成功回合汇总，同时给成功回合数；不能把快速失败解释为效率高 |
| 通过时间 | 五台均合法穿过出口的首个时刻；未全员通过记缺失 |
| 恢复时间 | 全员通过后，首次完成连续10步最终形状有效的时间减全员通过时间；未恢复记缺失 |
| `mean_path_length` | 每机器人实际接受位移长度累计后取五台均值，单位m |
| `mean_control_effort` | 实际速度变化对应的加速度平方积分，再对五台平均；是控制努力代理，不是电池能耗 |
| `mean_process_formation_error` | 每个active步执行后，按名义邻接边的相对位移误差取机器人均值，再在回合时间上平均，含停稳等待 |

过程指标公式及失败处理见 [METHOD.md](METHOD.md)。结果同时给所有回合与success-only汇总；失败提前终止造成的小里程或小控制努力不表示更优。

统计单位为独立训练seed。每队形报告五seed均值±样本标准差，并列每seed、每扰动/宽度得分和失败原因。测试初态数量与检查点数量不能作为训练seed数。选中模型和终点模型的比较使用同一训练seed与相同场景，报告配对差值；如给bootstrap区间，重采样训练seed并说明算法。不同队形的任务模板不同，不用独立初态数量制造显著性，也不在没有对照实现时给出优于原论文方法的结论。

## 可追溯产物和报告边界

运行目录统一为 `results/g_study/<formation>/seed_<seed>/`。研究登记位于 `configs/protocol.json` 和 `results/g_study/study.json`，包含协议、源码、模型及场景身份。保留训练配置、源码hash、场景hash、运行起止及用时、每更新指标、验证选型历史、所选与终点权重、模型hash和独立逐回合结果。注册完成后的训练和评测支持中断重入；首次注册若中断并留下未完成目录，程序拒绝覆盖，应保留该目录并选择新输出路径。正常完成清理滚动恢复点；精确续训只能用于完成同一既定预算，不能改变配置后沿用旧run身份。三队形所选actor另行导出TorchScript并检查连续动作和记忆与Python输出一致。

若存在未完成训练或测试，报告明确已完成/计划数量，不能把部分seed均值写成五seed结果。低成功率和预算不足属于结果；本轮不注册更多模块、地图或按测试反馈调参。当前证据仅支持所测理想局部量测下的固定五机器人仿真，不等同于实机通信、传感噪声或未知地图泛化验证。
