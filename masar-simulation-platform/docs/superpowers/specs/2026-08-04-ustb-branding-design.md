# 北京科技大学标识接入设计

状态：已获用户方案确认，待书面复核  
日期：2026-08-04

## 1. 目标

在不改变 MASAR 平台功能、顶栏高度和左侧品牌结构的前提下，增加北京科技大学的
学校标识：

1. 浏览器标签页使用用户提供的圆形校徽作为 favicon。
2. 页面左上角现有的 `M` 方框、`MASAR` 和“群体机器人验证台”保持不变。
3. 顶栏右侧新增北京科技大学中英文标识，并将“控制面在线”状态向左移动。
4. 学校标识去除原图白色背景，与现有深色界面融合。
5. 不改变控制面状态来源、Run 生命周期、工作区切换或面板布局。

## 2. 资源处理

用户提供的两张图片分别生成独立的静态资源：

- `frontend/public/brand/ustb-favicon.png`：由圆形校徽生成，裁去多余白边，圆形外部
  使用透明背景，保留校徽内部白色区域和蓝色图形。
- `frontend/public/brand/ustb-wordmark.png`：由包含校徽、中英文校名的完整标识生成，
  裁去四周空白并将白色底色转换为透明背景，保留蓝色图形与文字。

资源使用稳定的 `/brand/...` 公共路径，不通过 React 模块导入，便于浏览器 favicon
和页面图片共同复用 Vite 的静态资源目录。

## 3. 浏览器标签页

在 `frontend/index.html` 的 `<head>` 中增加 favicon 链接，指向
`/brand/ustb-favicon.png`。页面标题继续使用“MASAR 群体机器人验证台”，不增加学校
名称，避免改变现有标签页文字识别。

favicon 只用于浏览器标签页，不替换页面内的 `M` 方框。

## 4. 顶栏布局

桌面端顶栏继续保持 64px 高度，并由左到右分为四个区域：

```text
┌──────────────┬──────────────────────────┬──────────────┬──────────────┐
│ M / MASAR    │ 群行为 / 探索 / 完整搜救 │ 控制面在线   │ 北科大标识   │
└──────────────┴──────────────────────────┴──────────────┴──────────────┘
```

- 左侧 MASAR 品牌区维持现有宽度、内容和视觉样式。
- 中间任务导航继续占用可伸缩空间。
- 控制面状态成为学校标识左侧的独立状态区，状态点、文案和错误颜色保持原逻辑。
- 最右侧新增学校品牌区，通过左边框与状态区分隔；图片使用 `object-fit: contain`，在
  64px 顶栏内完整显示，不拉伸、不裁切内容。
- 学校品牌区不添加白色卡片、阴影或新动画，以透明蓝色标识作为唯一新增视觉元素。

## 5. 响应式行为

- 宽度大于 1120px 时，同时显示控制面状态和完整学校标识。
- 宽度不超过 1120px 时，沿用现有紧凑布局，隐藏控制面状态和学校标识，优先保证
  MASAR 品牌与三个任务入口不拥挤。
- 移动端继续保留 `M` 方框，学校标识不进入第二行工具栏，也不造成横向滚动。
- favicon 不受页面宽度影响，所有视口均使用圆形校徽。

## 6. 可访问性与错误处理

- 学校图片使用明确的替代文本“北京科技大学”。
- favicon 链接声明 PNG 类型。
- 静态图片加载失败时不影响控制面状态、导航按钮或任何运行操作；顶栏保留布局槽位，
  不让相邻元素发生覆盖。
- 本次变更不增加交互控件，不引入新的键盘焦点或动态状态。

## 7. 测试与验收

自动化测试覆盖以下行为：

1. 页面 `<head>` 中存在指向圆形校徽资源的 favicon 链接。
2. 桌面视口中，原 `M` 标识、控制面状态和北京科技大学标识同时可见。
3. 控制面状态的右边界不超过学校品牌区的左边界，两者不重叠。
4. 1120px 以下视口隐藏学校标识，并保持页面无横向溢出。
5. TypeScript 类型检查、Vite 构建和相关 Playwright 布局测试通过。

人工视觉验收使用桌面和移动端截图确认：透明背景干净、蓝色标识可辨认、顶栏高度
未变化，且学校标识没有挤压任务导航。

## 8. 非目标

- 不替换页面左上角 `M` 方框或 MASAR 字样。
- 不修改页面标题、平台名称或现有配色令牌。
- 不改变控制面健康检查逻辑或状态文案。
- 不加高顶栏，不把学校标识放入命令工具栏或工作区内容区域。
- 不重构与学校标识无关的现有未提交前端改动。
